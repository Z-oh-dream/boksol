我太 boksol 0.5.4
Windows x64 便携版

启动
──────────────────────────────────────
完整解压后运行 boksol.exe。请保留随包的 engines 文件夹。
启动会先播放更新检查进度动画，再进入主菜单。该过程在本机完成。
主菜单使用“设置 → 键位”里绑定的上、下选择菜单，使用 L、R 切换作品。
底部显示当前实际键位，包括确认键。也可点击右上角的按钮切换作品。
在对战、录像和设置页点击左上角“菜单”，或按 Esc 返回首页。
“设置 → 游戏与汉化”有三个 ROM 槽位。点击“导入 ROM”可一次多选三份镜像，
软件按文件头的作品编号分别归槽。切换作品时会使用对应槽位的镜像。便携包不包含游戏 ROM。
设置、存档和录像写入便携包同目录的 data 文件夹。
GBA 与 DS 的本地启动和联机都在我太 boksol 的游戏页运行。
首次本地启动匹配版本的 ROM 时，会用内置初始档建立本地存档。已有本地档、
明确选择的存档和 ROM 同目录存档优先。选择“新建存档”可开始空白档。

联机对战
──────────────────────────────────────
双方使用支持同一联机模式的 boksol 客户端，并选择同一作品。
局域网对战时，双方处于同一网络，信令服务器地址留空。
远程对战时，在“设置 → 联机与录像”填写同一个信令服务器地址并保存。
信令地址以 ws:// 或 wss:// 开头。清空地址并保存后会切回局域网。
在同一页填写“名字”，配对时可以在房间名单里看到所有玩家的名字。
《续・我们的太阳》和《我们的太阳 DS》可选 2、3 或 4 人远程房间。
房主选好人数后先开始配对，房间满员后启动游戏。《新・我们的太阳》支持两人。
1. 对战页默认使用匹配 ROM 的内置档。也可在“对战存档”中改选本地档或导入档。
   点击“用此档练习”可在独立副本中使用所选存档。需要从头玩时可另选“新建存档”。
2. 一方点击“生成六位码”，即可得到类似 K7M-2QX 的随机码。
   输入时可省略分隔符或使用空格，大小写均可。也可使用双方约好的 4–16 位自定义码。
3. 双方填写同一个联机码，点击“开始配对”。大厅校验作品和 ROM SHA-256，
   自动分配玩家身份，准备好对战后在我太 boksol 内显示原作画面。
4. 双方的 ROM 与所选存档都匹配内置对战起点时，配对后直接恢复原作联机入口。
   该流程也接受与内置档内容相同的导入副本。
   《续・我们的太阳》在双方加入后按默认配置开战。
   《我们的太阳DS》自动进入无线对战房间。房主在“ルール選択”中设置时限、局数和场地，
   确认后双方在“キャラクター選択”中各自选择角色、武器和道具，再分别确认开战。
   《新・我们的太阳》由房主先选赛道，然后双方各自改装摩托并在原作里确认开赛。
   使用其他个人档时，双方加载各自的存档并在内嵌游戏页操作。GBA 入口为标题菜单 → LINK，
   DS 入口为 WIRELESS → 通信対戦 → DSワイヤレス対戦，随后选择原作存档槽。
   对于本说明列出的两份 GBA ROM，新档已预设光照校准和日本东京地区。
   游戏启动时使用电脑的当前本地时间，无需在原作中逐项确认。其他 ROM 版本沿用原作设置流程。

默认游戏键位为方向键移动，Z / X 对应 A / B，A / S 对应 L / R，
Enter 对应 START，Backspace 对应 SELECT。DS 的 V / C 对应 X / Y，下屏支持鼠标触控。
GBA 的 F11 / F12 分别减少或增加日照。可在“设置 → 键位”或游戏页的“键位”中修改。
选中要修改的项目后按新键。若新键已被另一项使用，两项会互换。改动自动保存。

地址留空时，使用双人局域网发现。配对使用 UDP 39465 查找同网络玩家，
随后使用临时 TCP 端口校验。GBA 通信使用 TCP 5738，
DS 通信使用 UDP 7064，游戏引擎的房间发现使用 UDP 7063。
远程配对和对战流量通过配置的 WebSocket 服务端传输。
《我们的太阳 DS》的三至四人房间会从各自选中的存档启动，需要从原作菜单进入无线对战。
该模式已验证房间配对与核心连接，原作无线房间的三至四人入场同步仍在验证。

观战
──────────────────────────────────────
主机在启动对战游戏后点击“开放观战”，复制新生成的观战邀请。
观战者打开“观战”窗口，粘贴邀请并点击“播放”。观战无需 ROM。
切到软件的其他页面时仍会继续发送主机游戏画面。最多四名观战者，端口 TCP 39466。
传输的是主机游戏画面，当前没有音频、公开房间或公网中转。

录像
──────────────────────────────────────
在游戏页点击“录制”，再点“结束录制”保存。设置中可开启联机自动录制。
录像是 MJPEG AVI，包含游戏画面，当前无音频，单次最多约 20 分钟。
录像页可按文件名查找、预览首帧、播放、导出或移到回收站。

汉化和存档
──────────────────────────────────────
本次提供的两份 GBA 文件本身已有简体中文。
《续・我们的太阳》对应 2012-02-06 版本（CRC32 1036EF7C）。
《新・我们的太阳》对应 2016-07-12 版本（CRC32 29CA5AE1）。
GBA 对照沿用所附 TPL 中的「强戈」「天鼓大人」「太阳铳」「跨界对战2」等译名，另补充 Sabata 对应「萨巴塔」。
《我们的太阳DS》为日文原版（CRC32 0F1F25DA），当前有中文对照。
DS 的武器和星灵兽使用所附《流星洛克人 完美合集》术语表中的基础名
「太阳枪」「黑暗剑」「阿斯兰」「托比」「奥托飞特」「莉莎」。
DS 联动词条「ボクタイＤＳフォース」对照为「我们的太阳DS之力」。
尚无随附的游戏内汉化补丁。可在设置中添加 IPS / BPS，或导入已在
外部打好 xdelta 等补丁的同编号 ROM。补丁应用于本地副本。
游戏原文件和存档原件留在原位置。每次配对都从选中的档案建立联机副本。
在存档列表中点击“导入存档”，可以复制同作的原生 .sav 或 GBA 的 .sa1。
《续・我们的太阳》内置对战档提供 99 级角色、对战武器和魔法。
《新・我们的太阳》内置对战档解锁车头、车身、轮胎、特殊组件，各类别六项可选。
《我们的太阳DS》内置装备对战档在第 1 槽，包含基础及追加武器、防具和星灵兽。
《续・我们的太阳》的 2012 简体中文版使用 SRAM 存档，可直接导入旧版 VBA 的 .sa1。

开发入口
──────────────────────────────────────
src/ 是 C# WinForms 客户端。App.cs 是入口，CodeRoom.cs 处理联机码和配对，
CoreSession.cs 连接原生模拟器核心。native/ 是核心封装，构建步骤见 native/README.md。
在 Visual Studio PowerShell 中运行 ./build.ps1，生成 stage/boksol.exe。
引擎及运行库就位后，运行 python package.py 0.5.4 在 outputs/ 生成便携包。
启动进度和更新接口在 src/StartupScreen.cs。可实现 IStartupUpdateCheck 并传给 Lobby。
