# 联机中文文本

`official-tpl.tsv` 同步自官方 TPL 校对工作簿。五列依次为作品 ID、条目 ID、GBA 原始文本位置、日文和中文。GBA 使用 GCL ID，DS 使用校对表行号。文本换行保存为 `\n`。 [查看校对工作簿](official-tpl.xlsx)

GBA 运行副本在原 ROM 的空白区存放译文与字形，并重定向对应 GCL 条目。`{VAR=n}`、原作的扩展字段和按键样式在编码时恢复为游戏指令。运行副本使用与所导入版本相同的联机身份。

`ds-fields.tsv` 记录经过原版画面验证的文本区域。每行依次存储像素范围、原字色类别、对齐方式、字格大小、条目 ID、保留图标后省略的译文前缀字符数、原字形掩码哈希、底色和字色。匹配到文本后，Windows 和 Android 就地绘制中文，保留画面的触控区域。录像与观战使用同一显示层。

`glyphs.bin` 使用 Noto Sans SC 的 16×16 位图字形。`BLT1` 后依次为小端 16 位条目数，以及每个字符的 UTF-16 码位和 16 个从上至下、最高位在左的像素行。
